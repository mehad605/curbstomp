# Optimization & Audit History

The documents in this directory (`ANALYSIS.md`, `BASELINE.md`, `FINDINGS.md`, `PROGRESS.md`, and `RESULTS.md`) are the **historical engineering logs** from the Phase 1–2 APK size, DEX, memory, and event-driven service optimization passes.

Because those documents were written prior to the layered architecture rewrite (`data/` · `domain/` · `services/` · `ui/`), some file names referenced inside them (such as the old `utils/AppBlockerUtils.kt`) have since been decomposed into dedicated domain/data/service classes.

For the **current codebase map, architecture, build, test, and release guide**, start with the root [`README.md`](../README.md).
